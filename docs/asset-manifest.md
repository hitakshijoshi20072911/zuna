# Zuna asset manifest

The existing raster files under `frontend/assets/images/` are original project assets already present on the branch. Sample photos are cropped into separate product images from the user-provided collages in `PICS/`; the originals are preserved and are not served directly. Detail-only panels are not used as standalone products. Other sample visuals use existing product assets or original local SVG illustrations.
